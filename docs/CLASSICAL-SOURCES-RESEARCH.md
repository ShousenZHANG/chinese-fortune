## 子平真诠：正文与现代文字分离

[电子版凡例](https://www.donglishuzhai.net/chapter/3712.html)明确：篇章按底本分为 47 篇，编号为整理时添加；校记与考辨夹在正文中。它还说明部分错字、异体直接修改而不出校。因此去掉注释只能得到“去除现代夹注的网络正文”，不能恢复为 1923 年印本的逐字转录。

已核实的三个重点正文入口：

| 文本 ID 建议 | 目录位置 | 原文来源 |
|---|---|---|
| `ziping-zhenquan/ch08` | 卷一，第八篇，论用神 | [3721.html](https://www.donglishuzhai.net/chapter/3721.html) |
| `ziping-zhenquan/ch09` | 卷一，第九篇，论用神成败救应 | [3722.html](https://www.donglishuzhai.net/chapter/3722.html) |
| `ziping-zhenquan/ch14` | 卷二，第十四篇，论用神配气候得失 | [3727.html](https://www.donglishuzhai.net/chapter/3727.html) |

这三页可见现代夹注标记 `〖校：…〗` 与 `〖東里山人按：…〗`。导入只取编号正文内容，剥离这两类成对括注；遇到括号不闭合或残留 `東里山人`、`據中州本` 等标记，应列为待审而不自动归入古文。电子版前言、凡例、读后附记不进入公版正文。古代序跋如收录，另设层级和作者。

本轮后续采集已完成 **47 篇正文和 4 篇古序跋**，保存于 `knowledge/sources/ziping/`，合计 28,266 字符（含标题），去除 172 处明确现代括注。胡焜序另出现 `（校：…）` 形式，已一并处理。`chapter001.html`–`chapter047.html` 对应编号正文，`chapter048.html`–`chapter051.html` 依次为胡焜序、赵舒翘序、李星科跋、赵舒翘后序；重点引用文件为 `chapter008.html`、`chapter009.html`、`chapter014.html`。来源目录和逐篇双 SHA-256 记录分别在 `directory.html`、`metadata.json`。

该站本机 HTTP 请求多次连接超时，因此采用浏览工具实际返回的正文段落重建 article 节点。元数据明确标为 `web_open_rendered_text_reconstructed_article`，不声称保存了原网页 HTML；提取范围须同时看到正文章题和页面字数/更新时间终界，去掉工具引用标记及现代夹注。本轮源目录齐备、文件摘要及现代标记检查通过，仍未完成逐字影像校勘。

实例：气候篇存在整理者将“冬水”改成“冬金”的记录。去注后的正文仍采用其改字，不应在引用时伪称完全照录育新书局本；需要精确用字时回到影像核对。[气候篇校记](https://www.donglishuzhai.net/chapter/3727.html)

可用于后续对照的原始出版物影像为 [1926 年文明书局《渊海子平·子平真诠》第 2 卷](https://commons.wikimedia.org/wiki/File:NLC416-13jh002326-46443_淵海子平_子平真詮_第2卷.pdf)：Commons 列秦慎安校勘、75 页、来源国家图书馆，提供公版扫描标签和目录。它与上述 1923 年底本不是同一版；本轮只检查元数据和 PDF 可访问性，未逐页校勘。Web PDF 提取未获得正文行，不能把该 PDF 自动视为可用的校对文本。

## 渊海子平：完整目录与实抓边界

[古籍典藏目录](https://luckclub.cn/bazi/001/)实际列出 305 个条目，其中 000 是目录，因此正文验收数量为 304。网页的原文位于 `#pane-original article#article-content`；白话译文、关键词、现代启示位于 `#pane-translation`，本轮保存时只保留原文 article。

本地来源快照位于 `knowledge/sources/yuanhai/`：

- `directory.html`：从原页面的实际链接生成的古文篇目清单，不包含网站现代简介。
- `001.html`–`304.html`：对应原文 article，不是整个网页。
- `metadata.json`：逐篇标题、来源 URL、抓取时间、文本 SHA-256、HTML SHA-256、成功或失败状态；`captured_chapters` 是实得数，失败不能补写成成功。

两端正文已实际阅读：[首篇](https://luckclub.cn/bazi/001/001/)、[末篇](https://luckclub.cn/bazi/001/304/)。首篇包含“崇领”“韩炉”等疑似录入错误。相同文字亦见于[黄文涂研究中心旧转录的首篇](https://sajumania.com/ebook/to01-06/to01-06-01-01.htm)；这提示二者可能同源，不能拿二者一致当作独立校验。旧站[七卷总目录](https://sajumania.com/ebook/to01-06/to01-06-index.htm)可作篇目比照。

## 授权与来源归属

公版古文原作、后来的原创注释、译文、网站编排分别登记。仅有“免费在线阅读”不能推导出整页现代材料都可自由再发布；这不改变历史公版原作本身的地位。

- 维基文库[版权信息](https://zh.wikisource.org/w/index.php?title=Wikisource:版权信息&oldid=2437011)说明贡献采用 CC BY-SA 4.0/GFDL；作品页另有公版标签。保留作品题名、贡献来源页、固定修订链接和适用版权说明，不要把整个第三方资料目录笼统改标为项目代码许可证。
- Commons 上述两份 1926 年扫描页使用 PD-scan/PD-China 等标签，并保留国家图书馆来源。这里记录网站的版权标识；不把它扩展为对所有地区、所有现代增补的统一法律结论。
- 东里书斋[网站综述](https://www.donglishuzhai.net/about/wangzhanzongshu.html)声明公益、免费阅读和共享古籍，未在本轮所读页面发现现代按语的明确开放许可证。本文方案仅保存可分离的公版正文，保留来源与编辑处理说明。
- 古籍典藏[首篇页尾](https://luckclub.cn/bazi/001/001/)要求转载注明出处。来源快照仅保存历史原文并逐篇署明来源；不保存其现代译文、关键词、启示。
- ctext 的[官方 FAQ](https://ctext.org/faq/ens)区分公版材料与其拥有版权的贡献，要求使用者自行判定具体材料状态；“Wiki”栏目不是整站开放许可。此次直接访问部分页返回 403，未进行绕过，也没有把搜索索引中的 OCR 当作已抓取全文。

## 完整性验收定义

1. **目录齐备**：限定书名、所选版本和目录，所有预期篇目都存在且正文非空。不能把 47 篇、54 篇评注本、五卷本和七卷网络本混为一版。
2. **内容可复现**：来源 URL、修订号或抓取时间、正文摘要和提取规则齐备；站点更新不能静默改变已发布版本。
3. **文本已校**：必须有同版本影像定位和逐条校勘记录。本轮取得全文快照不自动满足这一层。
4. **解释可用**：古文能检索只代表材料可查；应用规则还需条件、例外、作用范围及冲突说明，不能直接把历史断语转成用户结论。

本报告来源状态与下载状态有意分开；实际已抓取数量以相应 `metadata.json` 和导入验收报告为准。

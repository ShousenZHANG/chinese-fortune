# 个人择时：实际完成范围与剩余条件

核查日期：2026-09-12。本记录对应本地开发改动，基于 `86154ba`，不是新发行版本，也不是经验预测准确率报告。

## 已完成的可验证改进

- 每次请求先取当前所在地时间；本命与目标时间分别计算，已确认生时的每个人只排一次出生盘。
- 可行档期接到各人的年月日时事实及生效大运。事件经过多个时辰、交节或夏令时变化时，保留完整经过，不只看开始点。
- 最早和最晚可开始时间按实际分钟与占用安排求得；这些是现实安排范围，不是古籍给出的最佳分钟。
- 择时只在合并后的可行窗口细算，窗口外保留年月和大运背景。相同条件同样处理，不为体现个人差异而强行改变答案。
- 身份主次、生时、事件经度、可用档期和规则缺口分别报告。无可行档期时说明实际原因，不附无关的命理引文。
- 古籍检索核对7组指定跨段上下文：赴任、赴举、财务事项、交易、出行、移居、婚嫁。返回原文与哈希，同时保留未核条件；婚嫁这里只补入口及明确后续位置。
- 白话草稿先直答，再显示自然的日期和安排。引用古籍时，原文后立即解释本义及本次适用范围。首次可用 `include_research:true` 一次取得场景材料，复用已有出生盘。
- README、路由、六爻及择日等说明与实际收录状态同步；原始来源不进入运行包，现有用户计划及下载目录保留。

一个固定虚构案例的同粒度比较：整周小时事实为47,872字节、91段；候选窗口小时事实加其余年月背景为5,658字节、7段。这里量的是UTF-8 JSON，不是token；比较对象仅为目标事实包，不是整个对话或真实宿主用量。

## 为什么仍未开放完整八字的面试首选

1. **个人连接不等于完整八字。** 已收录的《奇门遁甲元灵经》卷八 `yuanling:c008:p0001` 在“又法占科名”讨论本人年干、星门和排除条件。这是比泛称“官就是工作”更具体的来源，但仅使用年干；不能将它称为完整出生八字排序。
2. **现有兼容盘不是该原例的完整复现。** 同书卷一 `yuanling:c001:p0001` 的阳九局例令天禽加兑。旧兼容转盘实现 `star_plate(5, 7, '阳遁')` 输出兑七天芮、中五天禽。原文与实现的盘法不同，本轮默认改用已核核心，天禽加兑与天任加中已修正；面试、考试的候选分段已接入。卷八独立例仍不支持据此补齐全盘，剩余组件待核。不能在这种状态下接入科名条款，宣布个人最佳面试时段已算出。
3. **转录中的关键疑字仍会改变条件。** 《选择要略》下卷 p0005 的“日本，命日”、p0110 的年支字形等需要校勘。保留原文比擅自修字后作确定判断可靠。
4. **两种取运例式不是全部取运算法。** 八类取运章节已完整取得，涉及根气、轻重、位置及救应的条件仍需有来源的具体判断。十年运程的依据不能直接给周内各日排序。
5. **一次事件不等于完整行程规划。** 本轮已接通2–8件事、不同地点和显式交通准备时间的联合可行性；共用出生盘，保留各事项依据。行程示例是可行组合，命理联合最优仍需要各事项完整规则。

原文入口：[《奇门遁甲元灵经》](https://zh.wikisource.org/wiki/奇門遁甲元靈經)、[《选择要略》下](https://zh.wikisource.org/wiki/選擇要略/下)。运行时使用冻结版本及逐段哈希；页面当前呈现不替代冻结来源，网页未返回某段也不能证明该段不存在。

## 开放个人排名前必须补完

# 内容覆盖与仍需核对的地方

这份记录区分三件事：收到了哪些文字、哪些解释已找到具体出处、这些解释在本次盘面是否适用。前两项做完，也不能直接声称个人预测准确。

## 调候：120 格逐条对照

本轮逐月阅读现有《穷通宝鉴》冻结木、火、土、金、水五章，结合有关季节总论，对照历史表的首选、次选和条件。每格记录在 `assets/tiaohou_provenance.json`，有段落 ID、原文 SHA256、一般候选、条件候选、偏差说明。摘要数字由条目计算，审核会检查摘要是否一致。

这里的“有条件支持”表示旧候选能在一般论或条件分支中找到支持，**不表示原表排序完全正确、所有分支齐全，或本人的使用条件已经成立**。条件候选也不是排名靠后的固定喜神。

三个清楚的冲突已从运行时候选来源纠正：甲未用丁庚而不是把癸放首位；己申所据三秋正文是癸先丙后；辛子的一般壬丙条件与水多才取戊的例外必须分开。乙丑在冻结木章缺少十二月乙木专段，查询不返回当月候选；冬月丙火一般论只列作背景，不能填补专月缺文。

同一章也有异文和疑误字。例如癸酉段末句“丙辛怕用”与前文辛为用、丙佐之相冲突；戊土春论有疑脱字。本轮如实标明，没有把自行改字称为古籍校勘。所有影像状态仍是 `not_checked`。

历史表保留原候选用于审计对照，已去掉笼统 `verified_against_source`、全局忌神和无人使用的冷热分。旧混合版本引文另存为 `historical_source_note_not_verified`，不作为新核验的原文。运行时通过以下接口取得当前来源候选及限制：

```powershell
python scripts/tiaohou_provenance.py --key '甲|未'
python scripts/tiaohou_provenance.py --audit
python scripts/classical_search.py --passage-id qiongtong:c002:p0028
```

库内穷通版本与印本的关系见 [CLASSICAL-SOURCES.md](CLASSICAL-SOURCES.md)。段落 SHA256 能发现文本变化，不能证明抄录无误。

## 现在仍没有覆盖的内容

- 紫微十五种组合保留为项目组合候选。完整古籍成格条件、例外、岁限作用与不同流派解释尚未逐条注册。
- 紫微亮度仍是项目四级表，原转录是七级；不能声称全表逐格或原刻已校。
- 六爻用神选择、纳甲全部细则、变爻沿用本卦六亲、动变生克、进退空破墓绝尚未形成完整自动判断库。当前条款把这些需要核查的条件显露出来，没有用关键词暗填。
- 调候的节内前后半月、透藏、合化、旺衰与格局分支均需本次盘面检查；120 个定位条目不能替代这些判断。
- 风水、面相、手相、测字、姓名、合婚、生肖、星座、塔罗等保持点名启用，保留各自能解释的方法与边界，没有为增加条数制造“古籍已验证”规则。

本轮验证包括冻结引文与 SHA256、跨方法误用、篡改盘面引用、未核条件冒称支持、闰月来源不匹配，以及调候冲突、缺文和条件分支的具体反例。它们验证实现边界，不构成预测准确率评测。

# 白话输出示例

示例资料：公历 2000-01-15 10:30，男，东经 120°，UTC+8，子正换日。本例只说明原局，不推今年运势。每次实际计算仍先取得用户当前所在地时间。

问题：“这个八字主要有什么特点，能直接确定用神吗？”

---

现在能确定的是盘面结构，还不能直接定一个唯一用神。

四柱是己卯、丁丑、壬申、乙巳，日主是壬水。“日主”就是这套分析中用来比较其他干支的中心。

先看月支丑：其中藏己、癸、辛，分别对应正官、劫财、正印。己也出现在年干，所以这张盘可以从月令中的正官继续查起。“藏”是包含在地支里，“透”是同一个天干出现在上面一排；这说明位置关系，还不表示格局已经成立。

《子平真诠》说：“八字用神，專求月令。”接下来的条文还要看其他干支怎样配合。因此，不能只看到正官就断定事业顺利，也不能直接对应到某个职业。[论用神，第一段](https://www.donglishuzhai.net/chapter/3721.html) · 本库段落 ziping:c008:p0001。

这个盘还同时透出伤官和正官，但不能据此说工作一定不顺。《滴天髓》写的是“傷官見官果難辨，可見不可見”，并没有给出一概判凶的结论。要继续核对财、印等条件是否真正起作用；“盘里有这个字”和“它能解决问题”是两回事。[所收转录](https://zh.wikisource.org/w/index.php?title=滴天髓/06&oldid=844363) · 本库段落 ditian:c006:p0007，后续注文单列。

下一步应对照月令条款检查成败与救应；若讨论调候，再单独核对寒暖条件。现在不把不同算法的候选合成一个“标准答案”，也不据此推入职日期或收入。

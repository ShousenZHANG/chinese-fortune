**格局为什么从正官入手？** 月支丑藏己，年干又见己；以壬日主看，己为正官，所以程序把正官格列为候选。这解释了取格的依据，但不表示已经判定格局清纯或事业顺利。《子平真诠》把月令取用与全局成败救应连在一起讨论，因此还要检查其余干支的配合。[论用神](https://donglishuzhai.net/chapter/3721.html)；[论用神成败救应](https://donglishuzhai.net/chapter/3722.html)

**伤官和正官并见，能否直接判凶？** 不能。这张盘年干己为正官，时干乙为伤官，两者确实透出；但“并见”只确认了组合存在。财、印及身强弱的具体作用还没有完成逐项核验，因此不能据此说一定与领导冲突或婚姻不顺。《滴天髓》该条正文为“傷官見官果難辨，可見不可見”，同页注文另分条件。[格局论转录](https://zh.wikisource.org/w/index.php?title=滴天髓/06&oldid=844363)

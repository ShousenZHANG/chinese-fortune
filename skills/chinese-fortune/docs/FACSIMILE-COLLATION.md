# 五处短句的异版影像核对

已对照 1926 年文明书局《子平真诠》扫描图，逐字查看下列五处短句。**这是独立见证版本的局部核对，不是默认知识库底本校勘完成。** 不改原文、不裁定哪一版本正确，也不提升全书或默认段落的 `facsimile_checked` 状态。

版本与页码来源见 [候选记录](FACSIMILE-CANDIDATES.md)。机器可检索记录见 [facsimile_witnesses.json](../assets/facsimile_witnesses.json)，含版本 ID、固定来源、PDF SHA-256、冻结段落 SHA-256、双方摘句和异文。

以下摘句去掉标点、空格与换行，但保留用字。PDF 页码从 1 起算，不能与书中印页混用。较长段落只认证摘出的范围。

正常查询用 `python scripts/classical_search.py --witnesses ziping:c031:p0004`；不带段落编号列出全部短句见证。工具核对见证指向的冻结段落摘要与摘句，不声称重新检查了未安装的 PDF。

| 记录与段落 | PDF 页／印页 | 逐字核对范围与结果 |
| --- | --- | --- |
| `ziping-w1926-001` / `c008:p0001` | 23／十 | `八字用神專求月令以日干配月令地支而生尅不同格局分焉`：所核短句同文。 |
| `ziping-w1926-002` / `c009:p0006` | 26／十三 | `如官逢傷而透印以解之`：所核短句同文；这里只核这一个救应条件，不将后面的其他救应整段算作已校。 |

| `ziping-w1926-005` / `c031:p0005` | 49／三十六 | 李参政命例：影像为 `庚金混煞`，冻结转录为 `庚金混雜`。所核其余文字同文。四柱 `庚寅乙酉甲子戊辰` 中的官取自酉支，不能把“官必须明透”当本例前提。 |

默认库来自东里书斋网络整理文本，标明以 1923 年绍兴育新书局本为底本、另本参校并由整理者择字；它并非底本影像的忠实逐字转录。因此，影像差异先记录为版本异文，不能未经底本核对便认定为录入错误。

这五处由协作模型代理查看页面图像核对，尚未有第二位校勘者复核，不冒称人类专家校勘。没有把文字一致当成命理断验正确。后续增加条目仍须逐句定位、保存异文，并限定已核范围。

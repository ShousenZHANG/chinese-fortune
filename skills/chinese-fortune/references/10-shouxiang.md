# 手相：掌纹辨认与传统术语

用户明确点名时使用。当前能力是描述看得见的掌纹、解释术语与指定原文，遵循[输出契约](22-output-contract.md)。没有自动掌纹识别或经验证的个人预测模型。

## 阅读顺序

1. 确认是哪只手、照片方向及清晰度；需要比较时分别记录两只手，不把它们固定当成先天与后天的测量。
2. 先定位纹路，描述走向、深浅、连续、分叉或交叉。照片光线和手势会影响可见程度，模糊处不补画。
3. 解释用户点名的传统线名。线名与实际功能不同，长度或条数不能换算成寿命、智力、职业成就或结婚次数。
4. 用户要古籍解释时，先核定版本与段落；未收录的书不能宣称已逐条验证。

## 主要掌纹词汇

| 常用名称 | 通常指向的可见位置 | 描述重点 |
|---|---|---|
| 生命线（Life Line） | 拇指根周围向掌底弯曲的纹路 | 弧度、走向、连续程度 |
| 智慧线/头脑线（Head Line） | 从拇指与食指一侧横向进入掌心的纹路 | 与其他纹路起点是否相连、末端方向 |
| 感情线/心线（Heart Line） | 靠近指根、从小指侧横向延伸的纹路 | 长度、分支、位置 |
| 事业线/命运线（Fate Line） | 掌心中向中指方向延伸的纵纹 | 是否清楚可见、在哪一段出现 |
| 婚姻线（Marriage Line） | 小指根下方掌缘附近的短横纹 | 可见数量与位置，不对应婚姻次数 |

太阳线、财运线、健康线、旅行线等也属于传统线名。名称中的成功、财富、健康不是从掌纹测出的数据。

## 特殊形态

| 术语 | 可描述的形态 |
|---|---|
| 通贯掌/断掌 | 横向主褶皱贯穿掌面的形态称呼 |
| 岛纹 | 纹路分开后再汇合形成的小封闭区 |
| 十字纹 | 两条纹路交叉 |
| 星纹 | 多条纹路相交 |
| 链状纹 | 连续的小环或断续结构 |
| 分叉 | 一条纹路末端或中段分成两支以上 |

这些是形态标签。避免把旧有性别差别、褶皱形状或指长比例转成优劣评价；也不把掌纹分段标成年份，预测某时患病、迁居或离婚。

## 传统体系与来源

中国相书有掌中八卦等分区，西方资料常用行星丘、主要线等名称。它们并不是同一张解剖图，具体位置需随所读版本核对；本页不把不一致的位置表硬合并。

《神相全编》与 Cheiro 的手相著作可作为阅读线索，尚未纳入本项目五书全文库。书名里的“科学”或旧书中的医学比附，不能充当现代医学证据。

## 白话示例

“这条纹路在中段分成两支，照片中右侧那支更浅。手相资料一般称它为分叉；它不能说明你一定会换工作。如果你关心换工作，我们可以根据你已经提供的工作情况讨论。”

用户问某条纹叫什么时，完成定位和命名即可。用户提到疼痛、异常变化或疾病担忧时，按实际症状引导寻求医疗帮助，不用掌纹进行诊断或安慰。

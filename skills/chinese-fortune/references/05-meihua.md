# 梅花易数：取数、体用与白话解释

用户明确点名时使用。先完成上卦、下卦、动爻、变卦与体用，再按有出处且条件齐全的条款解释。遵循[输出契约](22-output-contract.md)。

## 一、取法先固定

`python scripts/meihua_cast.py --help` 查看现有入口。时间法默认 `classical`：年用地支序数，月日用农历数，时用地支序数。源条款见《梅花易数》卷一[年月日時起例](https://zh.wikisource.org/w/index.php?title=梅花易數/卷一&oldid=2690596)。这是转录级依据，未校原刻。

当下起卦先取得用户所在地当前时间；跨地、历史时刻与请求时刻分开。闰月需选明规则，原起例未解决的现代时区、日界及闰月取数约定要保留说明。`legacy-gregorian` 是明确选择的旧公历兼容法，不能称古籍年月日法。

## 二、起卦步骤

### 2.1 卦数与爻数

先天数为乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8；除以 8 余 0 按 8。动爻除以 6 余 0 按 6。六爻从下往上编号。

### 2.2 年月日时

设年支序 + 农历月 + 农历日为 A，时支序为 H：上卦取 A 除 8 余数，下卦取 A+H 除 8 余数，动爻取 A+H 除 6 余数。子为 1，依次到亥为 12。

例：乙丑年三月初四申时，A=2+3+4=9，A+H=18，得乾上兑下天泽履，上爻动为兑为泽。例子展示算式，不证明事件结果。

### 2.3 报数

项目双数入口取第一数为上卦数、第二数为下卦数、两数和取动爻。不同文献可能加时，使用前必须固定，不能事后换取法。

例如 37、98：上巽、下兑、第三爻动，风泽中孚变风天小畜。中孚从初到上是 1,1,0,0,1,1，第三位变成 1，得到 1,1,1,0,1,1。

### 2.4 文字、声音与物象

只使用用户实际给出的材料，说明按字数、笔画还是象类；核定简繁与笔画。一个事物可能有多个象类时明示歧义。不要编造当时鸟鸣、天气或路人作为外应，也不为得到目标卦反复换算。

## 三、本卦、互卦与体用

本卦是原六爻；变卦只翻转动爻。互卦取二三四为下互、三四五为上互。这里“本、互、变”的次序是解释结构，不保证现实会按现状、过程、结果三阶段发生。

单动爻在下三爻：下卦为用、上卦为体；在上三爻则相反。体通常表示本次主体，用表示所问的另一侧；先把所问对象讲清楚。

## 四、体用关系

| 关系 | 可确认的五行结构 | 传统取意方向，需看条件 |
|---|---|---|
| 比和 | 体用同五行 | 同类、相接 |
| 用生体 | 用五行生体 | 支持主体 |
| 体生用 | 体五行生用 | 主体有所付出 |
| 体克用 | 体五行克用 | 主体对用的制约 |
| 用克体 | 用五行克体 | 用对主体的制约 |

先明确关系来自本卦、互卦还是变卦，再核相应条款。用克体不能直接译成对方害你，体克用不能直接译成得财；关系表不产生个人吉凶总分。

## 五、季节条件

需要节令精度时，另核所用文献及节气边界；没有可靠判据时保留未知，不用 +3、-2 一类主观权重生成“古法吉凶”。体用、互变、季节条件相反时逐项说明，不能多数表决。

## 六、完整而有限的回答

以风泽中孚三爻动为例：上巽木为体，下兑金为用，原卦用克体；下卦变乾金，五行关系仍是金克木。互卦为艮上震下山雷颐，不能把互卦两个部分都当成同一关系。

白话可说：“按这次取法，表示主体的木与对面的金形成制约关系；变化后这层关系仍在。它描述的是这套传统方法里的结构，不能单独确定这件事成败。你问的是合同还是待遇，会影响接下来该核哪类条款。”若问题已明确，继续读相应条款并完成已支持的分析，不重复追问。

## 七、古例与应期

卷一观梅例记辰年十二月十七日申时：34 取上兑，43 取下离和初爻动，泽火革变泽山咸，互卦天风姤。可用它复核取数和变卦。文中事件叙事属于古书记载，不当作现代验证；也不把原例中的人物或伤害移植给用户。

本项目没有经过核验的通用应期引擎。不能把卦数直接当“几天后”、把木金等五行变成人身伤害、把偶遇动物加成吉凶分。用户询问历史应期取法时，定位完整原文后说明该例具体怎样推，不推广成无条件公式。

## 八、与其他方法的区别

梅花的体用不是六爻用神，也不是八字用神。报数与随机摇钱的方法、输入和含义分别记录。其他书名仅作查找方向；不把本页称为《梅花易数》全书校注或完整规则库。

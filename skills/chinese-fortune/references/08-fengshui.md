# 风水：空间资料与传统方法

用户明确点名风水时使用。当前没有完整风水排盘脚本，有把测量角度换成二十四山的 `scripts/fengshui_measure.py` 和年、月紫白九星 `scripts/zibai.py`；能解释坐向、二十四山、八宅和玄空的结构，并据用户实际空间资料提出布局观察。遵循[输出契约](22-output-contract.md)。

## 先拿到哪些资料

需要有方向的平面图、门窗与主要家具位置、周边遮挡、空间用途及用户实际困扰。要研究坐向，再记录测量角度、位置与磁北/真北约定。要排宅运，还需要建成、入住或修缮的时间与所选起运口径，不能仅凭生年造一张宅盘。

若只有照片，先描述图中可见的空间和遮挡；未拍到的结构不补。若没有方向，仍可讨论已知通道、光线、私密性和使用需求，涉及方位的判断等资料齐全再做。

## 二十四山与坐向

一周 360° 分为 24 份，每份 15°。坐与向相反，相差 180°；先确认用户给的是哪一个。

| 方位 | 三山 | 角度 |
|------|------|------|
| 北 | 壬、子、癸 | 337.5° - 22.5° |
| 东北 | 丑、艮、寅 | 22.5° - 67.5° |
| 东 | 甲、卯、乙 | 67.5° - 112.5° |
| 东南 | 辰、巽、巳 | 112.5° - 157.5° |
| 南 | 丙、午、丁 | 157.5° - 202.5° |
| 西南 | 未、坤、申 | 202.5° - 247.5° |
| 西 | 庚、酉、辛 | 247.5° - 292.5° |
| 西北 | 戌、乾、亥 | 292.5° - 337.5° |

例如 90° 在卯的中央，270° 在酉的中央。若朝向 90°，其坐向相对为坐酉向卯。这个例子只展示角度分类，不能推出居住者的财运。

接近 7.5° 等分界时保留测量误差，不随意取整跨山。罗盘盘层、测量约定和具体流派须一并说明。

用户给了角度，用测量合同换算，不手算：

```bash
python scripts/fengshui_measure.py --bearing 92 --of facing --reference magnetic --error 3
```

三项都要用户确认：角度是朝向还是坐向（`--of`）、相对磁北（罗盘、手机指南针）还是真北（地图，`--reference`）、大约误差几度（`--error`）；知道当地磁偏角就加 `--declination`（东偏为正）换成真方位。输出分两块：`measurement` 是测量事实（用的参照北、误差区间），`tradition` 是二十四山分类（依《协纪辨方书》卷二 xieji:c002:p0009、p0011、p0012；每山 15° 由二十四方位等分推出）。误差区间跨两山时 `ambiguous: true`，照 `say` 说要复测，不取整定成一山。默认正针（定向用）；`--needle zhong|feng` 只在用户明说用中针格龙、缝针消砂纳水时用。这个工具不判吉凶。

## 紫白九星（年、月）

用户问「今年五黄在哪」「这个月紫白到哪一方」「流年飞星」，或要按紫白看某方能不能动工时用：

```bash
python scripts/zibai.py --date 2026-11-08 --sitting 子
```

依《协纪辨方书》卷八：年星按三元（康熙二十三年甲子为上元；上元甲子一白入中、中元四绿、下元七赤，逐年逆转），月星按年支（子午卯酉年正月八白、辰戌丑未年五黄、寅申巳亥年二黑，逐月逆转），入中之星顺布九宫（中→乾→兑→艮→离→坎→坤→震→巽）。书中年表一百八十格、月表三十六格都由测试逐格复算。换年按立春、换月按节，北京时间；交节那天不给 `--time` 时，交节前后两种都列在 `candidates`，照 `say` 请用户给时刻。

`--sitting` 给坐山（二十四山之一；只有角度时先用上面的测量合同换算，误差跨山就每个候选各给一次），输出坐、向两宫的年星、月星，并标一白、六白、八白、九紫是否到方：《协纪》所引宗镜说某方「得年家月家之紫白」也可修（xieji:c034:p0016），《选择要略》写作「遇三白，九紫」（xuanze:c002:p0532）。这只是可修的条件之一，不单独定吉凶；二黑、五黄等其余各星，这几段原文没有说吉凶，回答不要补。日、时紫白《协纪》未载，工具不算（见 `not_computed`）。玄空宅盘（下卦、替卦、宅运）不是这个工具，随包也没有《沈氏玄空学》。

## 八宅

东四卦为坎、离、震、巽，西四卦为乾、坤、艮、兑。宅卦、命卦与门位不是同一输入，不能只看某人生肖就替全屋定吉凶。

生气、延年、天医、伏位、祸害、六煞、五鬼、绝命是八宅的传统分类名称。即使某位置按选定算法得到“绝命”，也只能说明该分类，不能推出疾病、死亡、生育或婚姻结果。

需要解释某一取法时，列出宅卦、位置卦、所用变爻顺序及来源。当前未给完整逐条核定的八宅规则，不以未核出生年简表替代计算。

## 玄空飞星

玄空使用运盘、山盘、向盘等层次。九星名称与五行是基本词汇：

| 星 | 五行 | 传统星名 |
|---|---|---|
| 一白 | 水 | 贪狼 |
| 二黑 | 土 | 巨门 |
| 三碧 | 木 | 禄存 |
| 四绿 | 木 | 文曲 |
| 五黄 | 土 | 廉贞 |
| 六白 | 金 | 武曲 |
| 七赤 | 金 | 破军 |
| 八白 | 土 | 左辅 |
| 九紫 | 火 | 右弼 |

三元九运以九个二十年区段组成 180 年周期；现代常用序列把 2024—2043 列为九运。具体交界、宅运取法及修缮是否换运需按版本另核。这个年表不是地产、行业或个人收入的预测。

同一宫两星或三星并见，要分清哪个来自运、山、向或流年，再按已定位条款核相应形局。只看到 2、5、7 等数字，不生成病灾、火灾或刑伤断语；也不按“吉星数量”给房子打综合命运分。

## 把传统术语说成能理解的空间问题

| 用户给出的实际情况 | 可做的说明或比较 |
|---|---|
| 床或桌正处于频繁通行处 | 根据实际通道讨论干扰与私密性，比较移动后的使用便利 |
| 直射光影响工作 | 按实际时段、窗向和使用需求比较遮光或桌位 |
| 家具挡住出口 | 根据真实尺寸核查通道是否可用，不以方位吉凶决定保留 |
| 用户担心“横梁压顶” | 解释术语指向的位置，再区分视觉压迫、实际结构与使用感受 |
| 用户问“财位”放什么 | 说明这是所选方法的方位名；摆件不产生收入保证 |

建议只建立在实际空间资料上。不能把建筑、照明或通风的常识当成整套风水预测的科学证明。结构、消防、电气等专业问题交给合适专业人员，不用术数代判。

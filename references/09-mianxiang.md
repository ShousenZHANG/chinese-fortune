# 面相：外观描述与相书阅读

用户明确点名时使用。本项目能解释传统术语、描述用户提供的可见特征；不从外貌识别人格、能力、健康、财富或命运。遵循[输出契约](22-output-contract.md)。

## 如何回答

1. 分清用户要外观描述、某个术语释义，还是阅读古籍。外观描述只说可见形状、位置、表情；照片不清处说明看不清。
2. 解释术语所在部位，再解释它在指定相书中的传统主题。需要古籍判断时先定位版本、章节与前后文，不把民间转述加引号冒充原文。
3. 完成所问的描述或文本解释。具体到个人时，保留形态观察，舍去不能由形态支持的性格、健康和际遇推断。

## 常见位置

| 术语 | 位置或结构 |
|---|---|
| 上停 | 传统面部分区的上部，常以发际至眉部划分 |
| 中停 | 眉部至鼻底附近 |
| 下停 | 鼻底至下巴附近 |
| 印堂 | 两眉之间 |
| 山根 | 两眼之间的鼻根附近 |
| 准头 | 鼻尖部位 |
| 地阁 | 下巴一带 |
| 法令纹 | 鼻翼向嘴角延伸的纹路 |
| 鱼尾 | 眼角外侧一带 |

三停、五官、十二宫是相书的分类方式，版本边界可能不同。观察到比例差异，只能描述差异，不能换算成早中晚年成绩。

传统五官别称包括眉“保寿官”、眼“监察官”、鼻“审辨官”、口“出纳官”、耳“采听官”。名字包含的寿、财等字不构成相应现实指标。

## 相书检索

《麻衣相法》《柳庄相法》《神相全编》《冰鉴》可作为用户指定阅读的书目线索；本项目五书库不包含这些书，托名、版本与引文须另核。不得把一张书目表称为这些书的完整知识库。

研究某句旧说时，说明“该版本怎样把部位与主题关联”，并指出其是否有相邻限制或不同版本解释。完整原文可作为历史材料读，不能转成用人、婚配、识人评分。

## 白话示例

问“我的眉尾下垂是什么意思”：可以回答“形状上是眉尾比眉头低。相书会给眉形起不同名称，但这张照片无法说明你的性格或将来。若你想读某本相书，我可以解释它怎样命名这类眉形。”

问“印堂是什么”：直接指出两眉之间，并解释这个部位名，不扩展成运势、疾病或道德判断。讨论痣或皮肤变化时不使用相书作医学依据。

本页不使用薄片判断、心理学或神经科学为相术背书，也不把“相由心生”说成已验证机制。

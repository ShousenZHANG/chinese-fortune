# 八字四柱 (BaZi / Four Pillars of Destiny)

> 子平之学,源于唐李虚中,成于宋徐子平。以人生年月日时四柱八字推断命运,合于阴阳五行之理。

**论断依据**：以《子平真诠》月令格局为主线，《滴天髓》《穷通宝鉴》《三命通会》《渊海子平》用于对应条款补充和对照，不按书名自动拼成一套算法。凡古籍无据者不妄断；有原文还须核条件，不能直接推出个人吉凶。完整纪律见 SKILL.md「解读纪律」。

## 一、八字概述

### 1.1 什么是八字

八字,又称"四柱八字"或"子平命理",是中国传统命理学中最重要的预测体系之一。它以人出生的**年、月、日、时**四个时间维度为基础,每个维度由一个天干和一个地支组合而成,共得四柱八个字,故称"八字"。


### 1.2 为何取四柱

四柱对应宇宙时空四个维度:

| 柱 | 时间单位 | 主管时段 | 代表人物 |
|---|---|---|---|
| 年柱 | 60甲子(60年) | 1—15岁(童限) | 祖辈、根源、社会大环境 |
| 月柱 | 节气(月) | 16—30岁(少年) | 父母、兄弟、青年事业 |
| 日柱 | 日干为命主 | 31—45岁(中年) | 自身、配偶、中年成就 |
| 时柱 | 时辰(2小时) | 46岁后(晚年) | 子女、晚年、归宿 |

- **日干**为"命主"(我),是全盘的核心,所有十神都以日干为参照定位。
- **日支**为"夫妻宫",代表配偶宫位。

## 四、十神详解

十神是以日干为基准,对其他七字(年干、月干、时干、年支、月支、日支、时支藏干)的五行关系进行命名。

### 4.1 十神定义表

| 十神 | 关系 | 阴阳 | 简称 |
|---|---|---|---|
| 比肩 | 同我 | 同性(同阴或同阳) | 比 |
| 劫财 | 同我 | 异性 | 劫 |
| 食神 | 我生 | 同性 | 食 |
| 伤官 | 我生 | 异性 | 伤 |
| 偏财 | 我克 | 同性 | 才 |
| 正财 | 我克 | 异性 | 财 |
| 七杀 | 克我 | 同性 | 杀(偏官) |
| 正官 | 克我 | 异性 | 官 |
| 偏印 | 生我 | 同性 | 枭(枭神) |
| 正印 | 生我 | 异性 | 印 |

**以日干甲木为例**:
- 比肩=甲;劫财=乙
- 食神=丙;伤官=丁
- 偏财=戊;正财=己
- 七杀=庚;正官=辛
- 偏印=壬;正印=癸

### 4.2 十神的条件化解释

十神首先是干支关系名称，不是人格、职业或六亲事件的判定。传统类比（印与学习支持、官杀与约束、食伤与表达、财与资源、比劫与同类）只用于组织问题，须说明是类比。

### 4.3 十神组合(常见结构)

| 组合 | 必查条件 | 输出边界 |
|---|---|---|
| 伤官见官 | 透藏、身强弱、财印作用、制化救应 | 不由并见直接判凶或婚姻失败 |
| 伤官佩印 | 伤官与日主强弱、印是否有根受损、财是否破印 | 格名不等于富贵、学历或职业 |
| 食神制杀 | 食杀力量、日主承受、财印是否改变制化 | 不以名称推断权位或成就 |
| 杀印相生 | 杀印是否相接、印能否扶身、是否另有破坏 | 不能承诺贵人或职位 |
| 财官相生 | 月令格局、日主承受、财官根气与损伤 | 不等于收入或职位必增 |
| 比劫夺财 | 财比轻重、位置、食伤通关或官杀约束 | 不指控朋友、伴侣造成损失 |

可核正文：《滴天髓·格局论》“傷官見官果難辨，可見不可見。”来源 `ditian-shangguan`；同页注文与正文分别存储。其它概括不是逐字古籍引文。

## 七、大运排法

> 大运是先天命局之外的"后天运程",每柱主管10年,与本命合参。

### 7.1 阴阳年与男女顺逆

**阳年**:甲、丙、戊、庚、壬年(年干为阳干)
**阴年**:乙、丁、己、辛、癸年(年干为阴干)

| 性别 | 阳年 | 阴年 |
|---|---|---|
| 男命 | 顺排 | 逆排 |
| 女命 | 逆排 | 顺排 |

**起点**:从月柱开始,顺/逆排60甲子。

**例**:某男命,1990年(庚午,阳年)甲申月生
- 男命阳年→顺排
- 月柱甲申之后顺排:乙酉、丙戌、丁亥、戊子、己丑、庚寅...
- 大运依次为乙酉、丙戌、丁亥...

### 7.2 起运岁数

**起运公式**:从出生日起算到下一个"节"(顺排)或上一个"节"(逆排)的天数,除以3,得起运岁数。

```
起运岁 = 距节气天数 ÷ 3
余1天 = 加4个月
余2天 = 加8个月
```

> 古法:三日折一岁,一日折四月,一时折十日(更精确)。

**例**:出生于公历1990年8月20日,顺排,下一节为"白露"(9月8日)。
- 距节天数 = 9月8日 - 8月20日 = 19天
- 起运岁 = 19 ÷ 3 = 6余1
- 起运 = 6岁 + 4个月 = 6岁4个月

故此命大运:6—16岁乙酉、16—26岁丙戌、26—36岁丁亥...

### 7.3 大运的看法

干支、起运时间和年龄属于计算事实；吉凶属于有条件解释。不能由“逢用神”直接判大吉，也不把十年前五年干、后五年支的某派简化当成统一事实。按采用版本核查原局、运干支和成败救应。

## 八、流年解读

先查原局结构，再查大运与流年如何作用于同一结构。合冲刑害仅说明关系，不能直接推出失业、离婚、疾病或具体事故。年层面的依据不能细化成月份、日期。没有独立验证不报告概率。

## 九、用神 / 喜神 / 忌神

### 9.1 分开格局、扶抑与调候

格局视角关注月令、配合与成败救应；扶抑视角关注承受与生克泄耗；调候视角关注具体日干月令条款和寒暖燥湿。病药、通关也须具体说明病在何处、何物能起作用。

程序的扶抑候选来自旺衰启发式，不宣称古籍定理。调候输出保留全部 primary_yongshen 与 secondary_yongshen 候选，不以列表顺序替代条件核验。不使用跨日干的“某季一律用某五行”口诀。

### 9.2 喜忌与分歧

`primary=null`、`status=needs_review` 表示未形成唯一结论。喜神不能机械定义为生用神、忌神不能机械定义为克用神。先检查所选规则内的作用和反作用；同一五行可能在不同组合承担不同作用。

《子平真诠·论用神配气候得失》说“論命惟以月令用神爲主，然亦須配氣候而互參之。”核对来源 `ziping-climate`。本项目分列观点，有分歧就说明，不自动以调候覆盖格局。

### 9.3 应用范围

不从候选五行直接推荐职业、配偶、投资、方位或颜色以保证结果。用户问传统象征时可解释对应关系，明确没有证明改变现实结果的效果。

## 十、六亲

六亲宫位和传统十神类比可作文化说明；不能由一颗星、一组冲合判断父母遭遇、配偶忠诚、子女性别或数量。用户现实提供的关系信息另列，不当成预测命中。传统“克夫、克妻”等措辞不得用于指责个人。

## 十一、健康

五行与脏腑的古代对应只作思想史或文化解释。八字不能用于个人诊断，也不依据五行多少推出器官疾病、寿命或伤残。健康问题应回到实际症状与专业评估。

## 十二、各领域解读框架

| 所问领域 | 先回答的内容 | 必须避免 |
|---|---|---|
| 事业 | 已核结构与所选条款如何相关，哪些条件未核 | 官星即入职、印星即合同、某月必获 offer |
| 财富 | 传统资源与生克象征及局限 | 富贵数额、交易方向、收益保证 |
| 感情 | 传统宫位说法与现实沟通信息分开 | 因神煞判不能结婚或指控伴侣 |

## 十三、输出示例与评估

## 十四、常见误区

### 14.1 排盘误区

1. **以农历正月初一为年柱起点** → 错;应以**立春**为界
2. **以农历每月初一为月柱起点** → 错;应以**节(非气)**为界
3. **以子时为日界存争议**:
   - 主流:23:00—00:00为夜子时(算前一日),00:00—01:00为早子时(算当日)
   - 另派:23:00—01:00整体算下一日(子时换日)
   - 实务建议:用前者(夜子时归前日,早子时归后日)
4. **忽略真太阳时校正** → 偏离时柱判断;西北、远东地区误差极大
5. **忽略时区**:民国前不同地区有地方时;海外应用当地经度

### 14.2 判旺衰误区

1. **只数十神个数不看力量** → 错;月令、通根、透干权重不同
2. **只看天干不看地支** → 错;地支力量更稳定
3. **不看刑冲合化** → 错;合化变质、冲克失力,需综合判断
4. **机械套从格** → 错;从格条件极严,极少见;勉强套从格则全错

### 14.3 取用神误区

1. **不分扶抑、调候、通关、病药混用** → 取用神需对症
2. **混用体系**：调候作为所选格局主线的对照，不自动覆盖其他判断；核对具体条款。
3. **按数量取用**：多寡不直接决定喜忌，先核查各干支在所选条款里的作用。
4. **忽略大运** → 用神需考虑大运配合,某些用神在某些大运失效

### 14.4 解读误区

1. **涉及生死疾病**：只解释古文语境，现实健康问题依据症状与专业评估。
2. **以一神煞定吉凶**:神煞仅解释起法与命中位置，不进入默认八字判断的证据
3. **六亲对应**：注明所用传统口径；不把它套作现代关系的事实。
4. **现实建议**：依据用户实际情况，不宣称仪式、改名或风水保证改变结果。

# 八字：从盘面到有条件的解释

四柱记录年、月、日、时的干支；日干又称日主，是十神关系的参照。默认以《子平真诠》月令格局为主线，先确定取用，再看配合、成败与救应，不按工程旺衰分数定用神。

藏干表按本气、中气、余气记录支中所藏天干，这个顺序不等于固定力量比例。正格是普通月令格局的分类名称，与从格等特殊格局区别；是否成立仍须核条件。

“透”指天干出现在四柱的上排，“藏”指包含在地支之中；“根气”讨论天干在地支有没有支持、支持是否有效。出现同字可以直接核对，是否有力不能只数个数。回答用户时先用这层意思说明，再使用术语。

## 一次调用取得什么

`scripts/bazi_reading.py` 返回：

| 字段 | 用途 |
|---|---|
| chart_facts | 可固定的四柱、历法口径、起运和时间范围 |
| observed_structure | 月令藏干、天干位置、同字藏根位置 |
| rule_assessment | 官、财、印、食、杀、伤、阳刃、禄劫八家相关条件 |
| evidence_bundle | 对应完整段落、例外及书章来源，重复内容只传一次 |
| reading_support | 已核盘面事实，传统解释由本轮继续完成 |

不要再找 `ge_ju.status` 或 `yong_shen.views`，它们只在诊断接口存在。默认工具不接受三个 `--no-*` 诊断开关。输入方式见 [输入采集](00-intake.md)。

## 核查顺序

1. 先核出生资料、时区、日界与节气边界。未知时辰保留不随候选时刻改变的柱，不能保证总能固定三柱。
2. 根据月令透藏确定查读方向，核《论用神变化》的透干、会支、兼格。程序选出的“家”是候选，不是完成定格。
3. 看相关路径条件。可计算的出现位置由工具给值；强弱、制化、位置是否有效仍需结合全盘解释。没有透出不等于全盘不存在，原文说“有”不能擅改成“透”。
4. 同读成立、受损、救应。某条路径不成立，不等于整个命局失败；另一路成立也须核全部前提。
5. 问岁运再检索该家取运章节；原局规则不能直接支持某年某月的事件。问调候再查对应日干、月令和版本。
6. 记录依据，按 [输出契约](22-output-contract.md) 审核后用白话回答。资料已够时不止步于“还需核查”。

## 十神与常见组合

十神是关系名称，不是人格、职业或六亲事件标签。

| 关系 | 同阴阳 | 异阴阳 |
|---|---|---|
| 同我 | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀（偏官） | 正官 |
| 生我 | 偏印 | 正印 |

以甲为日干：甲比肩、乙劫财、丙食神、丁伤官、戊偏财、己正财、庚七杀、辛正官、壬偏印、癸正印。

“伤官见官”“伤官佩印”“食神制杀”“杀印相生”“财官相生”“比劫夺财”只指查读方向。先看在月令体系中的作用，再核强弱、位置、根气和干扰。“有印”不等于印能救应，“有合”不等于合去。

## 格局、扶抑与调候

格局看月令与配合；扶抑看承受与生克泄耗；调候看具体日干月令的寒暖燥湿。不能把候选列表合成“唯一最优五行”。

诊断工具的身旺、偏旺、中和、偏弱、身弱及特殊格局属于工程候选。正官格、七杀格、正财格、偏财格、食神格、伤官格、正印格、偏印格、建禄格、羊刃格、杂气格须另核取用。阳刃采用所选《子平真诠》五阳干口径，不混用其他阴干羊刃表。

从财格、从杀格、从儿格、从势格、从印格、化气格、一行得气格等尚不属于默认八家规则覆盖，需完整条款，不靠数量阈值定格。井栏叉、金神等另查原书，不以缩写表当充分条件。

```sh
python scripts/classical_search.py --list-books

```

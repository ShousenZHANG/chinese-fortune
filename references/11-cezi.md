# 测字：字形、字义与文化联想

用户明确点名测字时使用。当前没有测字排盘脚本；提供可检查的拆字过程和与问题相关的语言联想，遵循[输出契约](22-output-contract.md)。联想不等于字源学证据，也不推导个人未来。

## 完成一次测字

1. 记录用户实际给的字和问题，保留简繁、异体及多音字差异。输入不清时只补问那个字，不替用户选字。
2. 先说明可直接观察的结构与通常字义；需要字源、典故或笔画数时核对相应字典或原文。
3. 最多选两种有明确步骤的联想，每种说明是哪一笔、哪一部件或哪个读音带来的。补出的笔画不得藏在解释里。
4. 将联想写成可供思考的问题，结合用户已经说过的事实，完成与原问题有关的回答。不给人物身份、第三方意图、疾病、收入和发生日期下结论。

## 技法与可检查例子

| 技法 | 操作 | 示例 |
|---|---|---|
| 拆字 | 按实际部件分开观察 | “休”可看作亻与木；这是现代字形描述 |
| 添笔 | 明确加了几笔及位置 | “木”下部加一横成为“本” |
| 减笔 | 明确去掉哪笔 | “本”去掉下部短横成为“木” |
| 比形 | 比较相近字形的差别 | “未”和“末”两横长短不同，不叫减一笔 |
| 谐音 | 说明具体读音及同音词 | “期”与“七”可作语言游戏，不将七当事件日期 |
| 字义 | 从通行词义提出视角 | “衡”可联系权衡，讨论两个已知选项的取舍 |

偏旁与五行、笔画尾数与五行是不同术数约定，可能给同一字不同结果。需要使用时明示采用哪种约定及来源，不能说字典证明了一个字能补命局。

## 白话示例

用户写“休”问最近工作：“这个字左右是亻和木，可以借来想‘停一下、找个落脚点’。如果你说的工作量已经超负荷，实际可做的是先分出必须完成和可以延后的任务。这是借字帮助整理思路，字形本身没有告诉我们何时升职。”

用户写“门”问求职：“可以从入口这个字义谈你已经有的申请渠道，比较内推、直接投递和作品展示各缺什么。不能从一个门字判断某家公司一定录用。”

## 文献范围

《字触》等测字材料可作为书目线索，尚未纳入本项目五书库。谢石、邵雍的故事先查原出处，不把未定位的故事写成历史验证，也不伪引口诀。测字不是心理测验，不能借罗夏、潜意识或其他心理学名词宣称有效性。

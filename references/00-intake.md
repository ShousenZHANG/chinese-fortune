# 输入与时间

先提取已有资料，再一次问清影响计算的缺项。纯八字不需要姓名、曾用名或在世状态；不要求用户重复已明确的信息。

## 当前时间

每次算之前确定当前所在地时区。对话中已明确就复用；未知时询问城市或 IANA 时区，不用出生地、电脑时区或猜测的 IP 地址代替。等待期间仍可核不依赖当前时间的原局；当前岁运保持未定。

调用 scripts/request_time.py --current-timezone Australia/Sydney。取得一次 UTC 时刻和当地表示，同请求后续工具复用 --request-time、--current-timezone。

- 出生时间：出生当天的当地钟表时间、出生地及历史时区。
- 当前时间：现在位于哪里，用于“今天”“今年”与岁运参照。
- 目标时间：用户明确问的历史或未来时刻，优先于“现在”；目标地点可不同。

只给目标日期时，黄历日级查询可执行；时家起盘还需时分，不拼入当前时分或默认午时。公历年度和命理立春年界分别处理。

## 生辰资料

| 字段 | 处理 |
|---|---|
| 出生年月日 | 明确公历或农历；农历遇闰月须确认 |
| 出生时分 | 已知则使用；未知保留可固定的柱，日界或交节日还可能影响年、月、日柱；紫微需时辰 |
| 性别口径 | 用于传统大运顺逆等计算，按用户提供的字段传入 |
| 出生地 | 用 --city 查城市表；未收录时取得真实经度和 IANA 出生时区 |
| 问题 | 先回答最相关的一项，用户要求全面再展开 |

资料冲突或可能改变时柱时才确认。正常完整输入直接计算，在结果中简要回显采用资料。

## 边界

- 海外与历史夏令时：按出生日期解析出生地时区，不手工重复减夏令时。
- 不存在的当地时间：解释跳时空档，要求更正。
- 重复的当地时间：说明两次对应的 offset，用 --fold 0/1 选择。
- 时辰区间：分别核算候选盘；共同部分先说，变化部分明确指出。
- 未知时辰：内部午时仅供日历换算，占位不进入时柱或个人解释。
- 夜子时：明确采用子初或子正换日，不在正文偷换口径。
- 真太阳时：八字、紫微默认使用出生经度和当日均时差；钟表口径传 --time-standard clock。其他方法依对应条款确定。
- 节气边界：按精确时刻判断年柱和月柱；时分未知且可能跨界时保留候选。

## 展示与保存

正文只展示与问题相关的盘面。完整四柱、藏干、纳音、十神、月令、大运、流年、时间修正可按需展开。旺衰分数属于工程诊断；用神、喜忌、格局候选须另核条款。

## 数据处理声明

排盘脚本不主动保存生辰，用户输入不落盘。宿主对话记录、命令行历史和进程列表可能包含输入，保存与删除由对应宿主控制。额外保存时说明目的和位置。按 [输出契约](22-output-contract.md) 撰写正文。

# 生肖与地支关系

生肖用于记录传统年属相和地支关系，不凭属相推性格、职业或婚姻结果。用户点名时查询，不参与默认八字结论。

## 年界与工具

python scripts/zodiac_compat.py --help 查看 year、info、compat、taisui 参数。涉及“今年”时先取得用户所在地当前时间，再明确查询年份。

春节年界与八字立春年界不同，春节前后、立春前后不可只靠公历年份断属相。只有年份没有具体生日时，返回的是该年的概览，不能保证适用于年初出生的人。

## 关系怎么读

- 六合：子丑、寅亥、卯戌、辰酉、巳申、午未。
- 三合：申子辰、亥卯未、寅午戌、巳酉丑。
- 六冲：子午、丑未、寅申、卯酉、辰戌、巳亥。

这些是传统地支配对名称。“合”不证明两个人相处好，“冲”也不证明婚姻不能成立。伴侣关系应根据实际相处讨论。

compat 保留旧诊断分数时，会标 score_kind=legacy_heuristic_relation_index、score_calibrated=false，且 verdict=null。此分数不是兼容率或成功概率，正文只解释地支关系。

info 只列对应与关系；不再返回人格和事业标签。taisui 只解释本命、冲等关系，不给灾祸预测或拜太岁、买物品等化解方案。

## 白话示例

“这两个属相在地支表里属于六冲，这是传统的配对分类。它不能证明你们关系会差；如果你担心相处问题，需要看具体分歧。”

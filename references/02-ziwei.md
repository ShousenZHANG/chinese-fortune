# 紫微斗数：盘面、条件与解释

用户明确点名紫微时使用。遵循[输出契约](22-output-contract.md)；先完成与问题有关的盘面分析，再说明限制。紫微使用独立的宫位、安星及四化方法，不给默认八字结论投票。

## 一、一次排盘后的工作

1. 核对公历/农历、闰月、出生时间、出生地与换日口径。问今年时先取得用户当前所在地时间；指定流年则明确记录该年。出生时辰不明时只解释方法，不任造完整命盘。
2. 运行 `python scripts/ziwei_calc.py --help` 确认参数。正常完整解读保留主星、辅星、四化和三方四正；只有用户问盘面骨架时才用 `--brief-palaces`。
3. 从问题选相关宫位，说明该宫的主辅星、对宫、两个三合宫及四化落点。空宫的借星须标为借宫，不变成原坐守星。
4. 对每个组合说明脚本实际命中的条件；有无亮度、四化、夹宫和岁限限制须分别核查。候选格名不是已成格，更不是优劣等级。
5. 给出已能支持的结构结论。若只能完成盘面说明，明确缺的是哪条解释依据，保留完整盘面回答，不能把未核条款补写成个人结论。

白话顺序（在[输出契约](22-output-contract.md) 第 4 节要求的开头直答**之下**展开，不取代它；开头仍须先给结论、原因与本题最关键的限制）：本次看到什么 → 为什么这样判断 → 哪个条件会改变判断。普通正文不堆内部字段或十几个星名。

按需裁剪：`--no-da-xian` 省略大限，`--no-patterns` 省略组合候选，`--no-sihua` 省略各宫自化（保留生年及岁限四化）。仅在用户只查原局位置或盘面骨架时使用；完整解读保留相关数据，不能先裁掉再凭空补解释。

`--brief-palaces` 同时只附基础条款索引；完整原句、条件与来源可用 `python scripts/method_rules.py --method ziwei` 查询。正常完整排盘直接附已去重的来源及应用记录，未核条件仍保持待核。

## 二、十二宫与身宫

十二宫是传统分析的主题目录。宫名不提供现实事实；例如财帛宫不是收入数据，夫妻宫不是伴侣行为证据，疾厄宫不是医学指标。

| 宫位 | 本次可组织的主题 |
|---|---|
| 命宫 | 全盘起点及与三方四正的关系 |
| 兄弟宫 | 手足、平辈关系的传统主题 |
| 夫妻宫 | 亲密关系的传统主题 |
| 子女宫 | 子女、晚辈的传统主题 |
| 财帛宫 | 财务主题的星曜与四化位置 |
| 疾厄宫 | 相应宫位与历史用语说明；不作健康判断 |
| 迁移宫 | 外出与环境变化的传统主题 |
| 仆役宫（交友宫） | 合作、交往的传统主题 |
| 官禄宫（事业宫） | 职业主题的星曜与四化位置 |
| 田宅宫 | 居所主题的星曜与四化位置 |
| 福德宫 | 休闲、生活取向的传统主题 |
| 父母宫 | 长辈主题的星曜与四化位置 |

身宫叠在命、夫妻、财帛、迁移、官禄、福德之一，并非第十三宫。项目从寅宫起正月，顺数到生月，再逆数时辰安命、顺数时辰安身。十二宫从命宫依次逆排。这个结构可以复算，不能据此把某年龄或某领域定成人生必然重心。

宫位地址写作子宫、丑宫、寅宫、卯宫、辰宫、巳宫、午宫、未宫、申宫、酉宫、戌宫、亥宫，与命宫等主题宫名分开。仆役宫、奴仆宫、交友宫为相关历史别称，脚本采用奴仆宫。

手工推导仅在用户询问起法或做排盘研究时读 [02-ziwei-paipan.md](02-ziwei-paipan.md)。运行失败须先修输入或依赖，不改用未经检查的心算填满命盘。

## 三、来源与流派状态

《紫微斗数全书》卷二[固定转录版本 1963110](https://zh.wikisource.org/w/index.php?title=紫微斗數全書/卷二&oldid=1963110)包含安身命例、安十二宫例、安星诀与「一命宫」亮度文字。本项目未校原刻影像。

项目表并非逐项照抄这一转录：魁钺辛干、丙丁口诀及壬干四化等存在异文或取表差异；闰月处理也须看输出说明。应报告当前选择，不称所有流派共识。

`self_transformations` 是以宫干查四化，所化星就在本宫时标记自化。标签有自化禄、自化权、自化科、自化忌。它与生年四化不同，属于本项目采用的后起飞星概念；当前未给出独立核定的自化解释条款。离心、向心也只是飞化方向标签。按三合法读盘时可略过这部分，不把它归到《全书》已核原文。

大限以水二、木三、金四、土五、火六局决定起始岁数；阳男阴女顺行、阴男阳女逆行。结果是岁段与宫位对应，不是这十年内一定发生的事。问某月、某日或某时辰时，用 `ziwei_calc.py ... --horoscope-date YYYY-MM-DD [--horoscope-time HH:MM]`：`horoscope` 按安斗君诀（ziwei:c002:p0064）给出流年斗君，再顺推流月、流日、流时各落哪一宫，以及该层天干的四化星。各层口径（正月初一换年、闰月十五日后作下月、五虎遁月干、晚子时随 `--sect`）列在 `conventions`。外部对照（iztro-js 2.6.3，40 例 50 次运行）宫位全部一致；不同处只在 `--sect 2` 的晚子时，本项目流时时干按次日、iztro 按当日，流时四化随之不同。原书只直接载斗君起法，流月顺行、流日、流时是现代通行口径；按立春换年或节气定月的流派在边界日也会不同，须说明。没传日期时不要从本命 `dou_jun` 自己推流月、流日。

每层还有 `stars`：运（大限）、流（流年）、月、日、时五层各按该层天干安禄、羊、陀、魁、钺、昌、曲，按该层地支安马、鸾、喜，如流年的流禄、流羊、流陀、流魁、流钺、流昌、流曲、流马、流鸾、流喜，大限的运禄、运羊、运陀、运魁、运钺、运昌、运曲、运马、运鸾、运喜，月、日、时层同样以月、日、时开头；流年另有年解和 `twelve_gods`（流年支起的将前、岁前十二神）。`horoscope.da_xian` 是目标日期所在的大限（按虚岁找），未到第一个大限时为 null。这些流曜是 iztro 等排盘软件的通行口径（与 iztro JS 60 组对照全同），所选《全书》转录未载，引用时不说成原书安法。

宫位落点只是“这一层落在本命哪一宫、哪些星化禄化忌”，不是当天会发生的事；解释仍按本命宫星和原文条件，不把流日化忌说成当天出事。

## 七、三方四正与夹宫

三方四正 = 本宫 + 对宫 + 两个三合宫。对宫地支差六位，三合宫各差四位。例如官禄宫在戌，则连同辰、寅、午四宫看。

夹宫是前后相邻两宫，例如命宫子，亥与丑夹命；它不是地支六合。说明星是坐守、会照还是夹宫，不混写位置关系。

# 大六壬：支持的起课方法

先遵循[输出契约](22-output-contract.md)。脚本排月将加时、天地盘、四课、支持分支的三传；三传未支持时仍保留已算结构。它不自动给出个人吉凶结论。[方法规格和独立原例](../docs/QIMEN-LIUREN-METHODS.md)说明主本、分歧和未完成部分。

## 时间与输入

先取得用户当前所在地时间，另分清目标时刻和目标所在地。显式目标输入例：

```bash
python scripts/liuren_cast.py --date 2026-06-01 --time 14:30 --target-timezone Asia/Shanghai --question "了解这次起课的结构"
```

`--longitude` 仅记录，不进行真太阳时修正。日时使用目标当地钟面，日干支在当地 00:00 换日。有目标时区时，月将与年月干支先将真实瞬间转为历库的 UTC+08 钟面，再按实际交节判断；换月将用中气，换月建用节，二者不能混同。无时区时 `calendar_basis` 明确标为浮动钟面假设，无法保证交中气两侧的唯一月将，须补时区。

昼夜贵人与十二天将仍待逐项校勘；昼夜暂用当地 06:00–17:59 为昼的钟面代理，没有计算日出日落。不能称整盘已按当地天象完整验证。

## 四课的确定结构

月将加在占时上，再依十二支顺序排天地盘。甲寄寅，乙寄辰，丙戊寄巳，丁己寄未，庚寄申，辛寄戌，壬寄亥，癸寄丑。

脚本沿用的中气月将表如下，表名是传统十二神名称，并非对用户的形容。恰逢交中气时采用新月将；跨年用前一中气的实际记录，不猜定为大寒。

| 中气起点 | 月将 | 神名 |
|---|---|---|
| 雨水 | 亥 | 登明 |
| 春分 | 戌 | 河魁 |
| 谷雨 | 酉 | 从魁 |
| 小满 | 申 | 传送 |
| 夏至 | 未 | 小吉 |
| 大暑 | 午 | 胜光 |
| 处暑 | 巳 | 太乙 |
| 秋分 | 辰 | 天罡 |
| 霜降 | 卯 | 太冲 |
| 小雪 | 寅 | 功曹 |
| 冬至 | 丑 | 大吉 |
| 大寒 | 子 | 神后 |

一课是日干寄宫的上神，二课是其上神再上；三课是日支上神，四课是其上神再上。一课的五行关系按日干计算，不能误用寄宫地支的五行。例如辛金寄戌土而上见卯木，应为辛金克卯木。

## 三传取法

三传是按该法依次选出的初、中、末三个符号。不能把它直接等同于过去、现在、未来的确定事件。

| 取法 | 本版处理 |
|---|---|
| 贼克：重审、元首 | 先下贼上，无贼才上克下；重复同一上神不多算候选 |
| 比用：知一 | 多候选中恰有一个与日干同阴阳才取它 |
| 涉害 | 俱比、俱不比返回未支持；不取第一个替代 |
| 遥克：蒿矢、弹射 | 神克日为蒿矢，日克神为弹射；比用仍不唯一则未支持 |
| 八专 | 干支同宫且无克；阳从日阳顺三，阴从辰阴逆三，中末同取干上 |
| 伏吟 | 天地盘同位；有克用克，无克阳取干上、阴取支上，按刑、自刑换日辰和冲法取后传 |
| 反吟 | 天地盘相冲；有克用克，无克按井栏六日取法 |
| 昴星、别责 | 暂未实现；不共用酉宫兜底 |

主法固定为《六壬大全》四库本卷一入手法，八专从“论克不论遥”。伏吟、反吟和八专会重叠，按课体及有克条件分支，不能机械排列九个函数后逐个碰运气。

伏吟初自刑时换取另一侧日辰上神；次传自刑或子卯刑回初传时按主本补注取冲。反吟有克初末相同可以成立。八专“独足”也可以酉酉酉，不能为消除重复而人为换一传。

## 如何使用结果

`san_chuan.status` 是首要检查字段：`supported` 表示本版支持并执行该分支；`unsupported` 表示该取法尚未完成。后一种情况 `completion_status` 为 `partial`，三传及相关五行、旺相为空，但天地盘和四课仍可解释。必须告诉用户具体缺的是哪门取传，不能把 `ok:true` 当全盘完整，也不能补凑三传。

旺、相、休、囚、死是项目按季节五行计算的状态名，不是健康或生死判断。十二天将（贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后）是传统符号，当前尚无已注册问事解释条款，不从神名判断有人欺骗、外遇、败诉或病重。

回答先完成支持的分析：这次属于哪类课、哪些具体上下关系触发取法、为什么是这些三传。用普通语言解释“下贼”是下方五行克上方，并非某人有恶意；“官鬼”等六亲名称也不代表鬼怪或疾病事实。若用户问现实行动，使用其实际情况给建议，不能把盘面方向当寻人定位或把取传当投资与治疗依据。

# 直接回答：模板、禁用表与判据

本篇定 **摘要层怎么写**。层 2 的证据摆放仍按 [输出契约](22-output-contract.md) 第 4 节——每条判断「结论 → 盘面依据 → 古籍条款和适用条件 → 例外或分歧」，出处放在对应句旁。本篇管的是它上面那三句。

目标：删掉「说了等于没说」的句子，同时不删掉真话。这两件事的分界线在本篇的**限制句判据**。

## 首行按问句类型切

| 用户问 | 首行 | 例 |
|---|---|---|
| 怎么样、如何、好不好 | **结论** | 这卦好。 |
| 怎么办、该不该、选哪个、哪天 | **动作** | 买 Burgundy。 |
| 有没有、是不是 | **是／否** | 古籍没有这条。 |

首行之上不许有任何东西——表格、代码块、卦名、四柱串、`审核 0 错`、版本号，一律在其下。

## 模板

```
<结论或动作>：<一句依据>。<本题独有的限制，一句>。
```

三段都不能省。依据缺失时用「古籍没有这条」代替整个模板。

**例一**（问「这卦怎么样」）

> ❌ 这卦好，但好不等于稳，需要注意的是……
> ✅ **这卦好**：代表职位的那一爻落在你自己的位置上，当天月日都在生它。一项未决——最上面那爻动了冲它，条款没写冲怎么算。

**例二**（问「买哪个配色」）

> ❌ Burgundy 排第一，但它不会改变什么，仅供参考。
> ✅ **买 Burgundy**：你这盘的当月专段说取火，四色里只有它是火。银色也有一条条款撑（冬金喜比肩），比火少一条。

**例三**（古籍没有）

> ❌ 五书里查了「遗精」「房事」「色欲」全是零命中，唯一那条是壬癸日主的疾病表跟你不搭，而且你自己的 skill 也……
> ✅ **古籍没有这条。** ⟨层 2：查了 X、Y、Z，零命中；唯一沾边的 `sanming:c007:p0004` 是壬癸日主，不适用⟩

## 限制句判据

摘要里那句限制，**必须是本题独有的**。判据只有一条：

> 这句话换到别的卦、别的年、别的颜色上，还成立吗？
> **成立 → 套话 → 删。**

| 句子 | 换个卦还成立？ | 判 |
|---|---|---|
| 好不等于稳 | 成立 | 删 |
| 这只能当参考 | 成立 | 删 |
| 两年都不会自己变好 | 成立 | 删 |
| 最上面那爻动了冲用神，条款没写冲怎么算 | 不成立（这卦独有） | 留 |
| 银色也有一条条款撑，比火少一条 | 不成立（这四色独有） | 留 |
| 身弱这个判定是通行推法，不是古籍明文 | 不成立（这盘独有） | 留 |

## 禁用表

### 甲类 · 禁用（删了零信息损失）

出现在任何位置都报警。带 `← 正则` 标注的那条走正则，其余按字面比对。

```
仅供参考 | 只能当参考 | 参考而已 | 姑且听之 | 信不信由你
要说清楚的是 | 必须说清 | 先说清楚 | 说句实在的 | 老实说 | 说点真的
好不等于 | 不等于保证 | 不会自己变好 | 不会改变什么
我理解你想听什么
我看到的不是……是            ← 正则 /我看到的不是[^。！？]{0,24}[，,]\s*是/
```

会话末尾的整段文化参考声明**一次即可**——见 [输出契约](22-output-contract.md)「一次说明文化参考性质即可」那条。重复出现记为甲类。

### 乙类 · 限位（有信息，只许层 2）

**出现在摘要段（首个空行之前）报警**，出现在层 2 不拦。行数不作判据——摘要段可长可短，按空行切才和两层结构对得上。

```
给不了 | 答不上 | 排不出来 | 算不了     ← 后面必须紧跟「因为」
两书相反 | 起法分歧 | 两说并列
passage_id | precedence_version         ← 指裸字段名进摘要
transcription_status | facsimile_status
```

`passage_id` 进乙类指的是**字段名出现在白话里**，与本篇自检表「排名有没有 passage_id」不冲突：后者要求层 2 有出处，前者禁止把键名当白话。

**例外**：「古籍没有这条」当它**本身就是答案**时，允许且应当出现在首行。检查时先把这一句剥掉再扫其余部分——整段放行会让一句缺载声明替后面的并列话术挡枪。

### 保留（不许删）

以下**不进甲类表，在摘要段也不拦**；删了就是隐瞒：

- 本题独有的限制（通过上节判据的）
- 输家条款那一行「另说：……」——见 [裁决顺序](26-precedence.md)
- 条款前提不成立的说明
- 转录状态标注（在层 2）

## 发送前自检

- [ ] 首行是不是按问句类型给了结论／动作／是否？
- [ ] 摘要三段齐不齐：结论、依据、本题限制？
- [ ] 那句限制换个题还成立吗？成立就删。
- [ ] 甲类词一个都没有？
- [ ] 乙类词有没有跑进摘要段（首个空行之前）？
- [ ] 排名有没有 `passage_id`？没有就不许排。
- [ ] 输家条款那行留了没有？

本仓库外有一个可选的 Stop hook（`~/.claude/hooks/format-check.js`，**不随本包发布**）拦首行结构、甲类词与摘要段的乙类词，**它在答案发出之后才触发**，只能改善下一轮。上面这几张表才是真控制。

它曾有一段时间一次都没运行过——读的环境变量宿主根本不设，而它静默失败。所以「有个 hook 兜着」不能当依据；自检表是唯一实时生效的那一层。

## 配色一类的问题怎么答

「哪个颜色对我有利」这类问题，用 `fortune_ranking.climate_colors(日主, 月支)`。它按当月调候专段给出条款所取的五行及其对应颜色，带 `passage_id` 与哈希。

**它不是择时场景，没有进 `fortune_rules.py` 的 `SCENARIOS`。** 原因：没有候选窗口可排，登记成 scenario 会让人误以为它能给排名。

链条三段，第三段是空的，输出里用 `broken_link` 字段写明：

1. 日主 + 月支 → 当月专段 —— **有出处**
2. 专段所取天干 → 五行 → 颜色 —— **有对照表**，但表头自述「不证明方位、颜色能改变结果」
3. 颜色 → 「买这个对你有利」 —— **无出处**

回答时三段都要出现，不能只说第 1、2 段然后给个推荐。`tiaohou_provenance` 的 `review_note` 对庚金子月这一格写得很直接：「不把表名直接变成喜火的现实建议」。

**常见错误**：条款写「取丁甲」是两个五行（火与木），只报火就把两相的条款窄成了一相。

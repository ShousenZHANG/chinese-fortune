## 已完成的功能

### 大运：从三家扩展至八家

新增印、食神、七杀、阳刃、建禄月劫五家的 30 种取运情形，连同原有官、财、伤共 49 种。

| 类别 | 情形数 |
|---|---:|
| 正官 | 6 |
| 财 | 7 |
| 伤官 | 6 |
| 印 | 7 |
| 食神 | 5 |
| 七杀 | 7 |
| 阳刃 | 3 |
| 建禄月劫 | 8 |

每项携带原文段落 ID、校验值、可计算前提、解释性条件、上下文与例外。印轻见财、食重杀轻等反向条件单独保留；“透官/透杀”只检查天干，不能用藏干替代。未确定的格局、旺衰、去留或合化不自动变成总体喜忌。`conditional`、`partial`、`mixed` 和未提及状态不能压缩为一个吉凶分数。

### 格局：增加成败救应与变化核对

增加 46 条规则记录：9 条变化线索、5 条保留本格线索、八家各 4 类成格/败格/成中带忌/败中救应条款。默认八字解读加入 `geju_review`，区分可见事实、已排除条件、未知资料、解释性判断及出处。

“某字出现”“会支成员齐全”“前提命中”都不等于有效合化或最终成格。未知时辰不使用占位时柱参与判断。原文转录完整性和哈希校验不是影印版本逐字校勘；最终格局与喜用仍保留未判及核对路径。

### 使用体验与可靠性

- 八字、紫微、梅花、六爻、周易、奇门、大六壬、塔罗明确点名时均给出可执行入口。八个命令模板均经过真实 CLI 调用。
- 纯术语解释不再索取生辰；命宫、世应、体用等选对应资料。具体命盘、领属问法仍按个人分析处理。
- 单人、双人、多体系保留各自输入和岁运参考时间，已确认资料复用；两个人不混盘，多体系不合成“命运分数”。
- `--view compact` 去除重复说明和完整原文重复输出，通过索引保留条件、反例、出处及未判原因。大运数据可无损还原；完整视图仍可按需取得。
- 周/月短答恢复长度约束；详细大运说明可展开，短答不会把条件性结果改成确定喜忌。
- 精简结果可直接送入审核 CLI；自动事实记录与 full 一致，不需要另取大 JSON。新增解释仍须显式提供主张记录并做语义复核，不能拿自动事实审核的通过替代回答审核。
- `--report` 显式生成离线 Markdown/HTML；同一次计算生成正文和完整证据。报告须保存在技能目录之外，拒绝覆盖既有文件，转义用户输入，不加载远程资源。
- HTML 首屏显示已核结果和四柱，术语/条件与完整计算资料分层展开。已用浏览器验证首屏、展开/收起及键盘操作；未声称完成手机真机或屏幕阅读器全面验收。

接口变化与兼容方式见 [MIGRATION-5.10.md](../../docs/MIGRATION-5.10.md)。默认完整结果的 schema 为 2.1，紧凑视图是显式选项。

| 对比 | 中位减少 |
|---|---:|
| v5.10 compact 对已安装 v5.9.1 默认输出 | 61.62% |
| v5.10 compact 对 v5.10 full 输出 | 74.91% |

第一项各样例减少 52.24%–69.59%，达到本轮小样本“中位减少至少 60%”目标。不是每个样例都达到 60%。上述是字符数，不是模型 token、价格或延迟的节省率；按需检索原文仍产生后续调用。完整来源段落转为 ID 索引，不意味着可以跳过读取原文后再引用的要求。

## 真实宿主验收

用例：[cases.json](cases.json)，24 个任务、计划 32 轮，均为虚构资料。固定请求时刻 `2026-10-24T04:00:00Z`，包含日历/DST/未知时辰、时间范围、资料更正、两人分析、报告、施压改判、伪造引用、事后对照和重大决定边界。

### Codex

使用本机桌面自带 CLI `0.164.0-alpha.11.1`、实际模型 `gpt-6-astra`、reasoning `medium`，每个任务独立 ephemeral 会话，连续追问保留同一会话。普通任务只读；S18 在独立报告目录允许用户明确请求的保存，技能放在该目录外，并核对前后内容摘要不变。

首轮 24 项中 21 项完成，完成回答 28 轮；S17/S20/S21 在 240 秒上限内超时，未计为通过。S17 在跨盘原文核查后仍在生成长回答；S20/S21 停在说明读取后。不能仅凭日志认定三者都是产品代码错误或都是服务端错误。完成任务耗时中位 48.69 秒。

首次全局 CLI `0.147.0` 预检被服务端以版本过旧拒绝；保留失败记录后改用已安装的桌面版本，没有修改全局 CLI。

S18 两轮真实测试已生成报告，仅写出指定 HTML，未覆盖文件、未修改技能。完成回答经工具轨迹和文本复核；此处是单次小样本检查，不是独立盲评，也不能据此声称所有宿主回答都准确。

对三个超时任务各独立复跑一次，模型、effort、240 秒上限不变，仅改为单 worker，并保存到另一目录：S17 131.375 秒、S20 两轮合计 100.172 秒、S21 55.578 秒，全部执行完成。合并首轮成功与这一次复跑，24 项任务的 32 轮均取得完整回答；这不是“首轮 24/24 通过”。这三项复跑的工具结果与答案已经另行复核，未见明确的伪引用、强补未判或录用保证。

普通任务测试快照后又补了 compact 自动审核入口和 HTML 首屏展示；前者已用 full/compact CLI 等价与未知时辰/边界/篡改探针核对，后者另用 S18 真实保存和浏览器检查。没有把先前宿主结果谎称为最终 ZIP 的完整重跑。

实答语义复核发现 S05 一处 P2：回答把“截路空亡正犯限定仍待核”的时段写成直接避开要求，遗漏条件。已在工具的回答约束中绑定具体窗口，明确只能说“当前工具按表先筛除”，不得删去“正犯适用条件未核完”；并添加回归检查。新的 S05 独立宿主复测用时 89.531 秒，明确保留“工具按表暂先筛除，但原文正犯的适用限定尚未核完，不能说这些时间一定不宜”，另经独立定向语义复核通过。首次语义失败保留，不用其他任务通过抵消；一次复测不证明永不复发。S01–S12 共 13 轮、S13–S24 已完成部分及三项复跑共 19 轮已对照实际工具记录，除上述已修问题外未发现明确语义缺陷。
